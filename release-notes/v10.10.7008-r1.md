# Futu OpenD 10.10.7008-r1

这是本 fork 第一个面向普通使用者的正式发行版。使用者不需要克隆源码，也不
需要在本机下载 OpenD 安装包或构建 Docker 镜像。

## 快速开始

下载本 Release 附件中的：

- `futu-opend-10.10.7008-r1-linux-amd64.tar.gz`
- `futu-opend-10.10.7008-r1-linux-amd64.tar.gz.sha256`

校验并解压：

```bash
sha256sum -c futu-opend-10.10.7008-r1-linux-amd64.tar.gz.sha256
tar -xzf futu-opend-10.10.7008-r1-linux-amd64.tar.gz
cd futu-opend-10.10.7008-r1-linux-amd64
cp env.example .env
chmod 0600 .env
```

编辑 `.env` 后，首次登录并启动：

```bash
./futu-opend init
```

登录成功后，当前前台 OpenD 已经提供 API 服务，不要紧接着运行第二个容器。
该会话结束或主机重启后，使用 remembered 状态后台启动：

```bash
./futu-opend start
```

日志和状态：

```bash
./futu-opend status
./futu-opend logs
```

登录状态失效时执行 `./futu-opend reauth`。停止服务使用
`./futu-opend stop`；不要执行 `docker compose down -v`。

## 本次发布

- 提供无源码 Linux/amd64 运维包和简化管理命令。
- Compose 只拉取本次 CI 测试并按 registry SHA-256 digest 固定的 GHCR 镜像。
- 支持首次交互登录、记住密码状态的日常后台启动和非破坏性重新认证。
- RSA 宿主机密钥保持 `0600`，容器内副本为 `futu` 用户拥有的只读 `0400`。
- API 默认仅发布到宿主机 `127.0.0.1:11111`；Telnet 和 WebSocket 默认关闭。
- OpenD 以固定非 root UID/GID `10001:10001` 运行。
- 登录状态保存在命名卷中，停止命令不会删除该卷。
- CI 在发布前运行无凭据的 Layer 1 和 Linux/amd64 镜像 smoke test。

## 支持范围与已知限制

- 仅支持 FutuOpenD `10.10.7008`、Linux/amd64、Docker Compose v2 和单实例。
- 首次登录或重新认证必须由用户在私有终端完成，可能需要手机或图形验证码。
- OpenD 归档 SHA-256 是从固定官方 HTTPS 地址验证归档后计算的 TOFU 锁，
  不是富途提供的签名或校验文件。
- 运行基础仍为已固定 digest 的 Ubuntu 18.04 兼容环境，该版本已结束标准支持。
- 容器健康检查仅表示进程存活和配置一致，不代表登录成功或 API 业务就绪。
- 本项目与富途证券没有隶属关系，不解锁交易、不下单，也不授予行情权限。
