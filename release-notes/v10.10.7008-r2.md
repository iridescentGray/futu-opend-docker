# Futu OpenD 10.10.7008-r2

本次发行新增 macOS Apple Silicon（M1 或更新）宿主支持，同时保留原有
Linux/amd64 发行包。两个宿主包运行同一个经过 CI 验证并按 registry SHA-256
digest 固定的 Linux/amd64 OpenD 镜像。

## macOS Apple Silicon 快速开始

下载本 Release 附件中的：

- `futu-opend-10.10.7008-r2-macos-apple-silicon.tar.gz`
- `futu-opend-10.10.7008-r2-macos-apple-silicon.tar.gz.sha256`

校验并解压：

```bash
shasum -a 256 -c futu-opend-10.10.7008-r2-macos-apple-silicon.tar.gz.sha256
tar -xzf futu-opend-10.10.7008-r2-macos-apple-silicon.tar.gz
cd futu-opend-10.10.7008-r2-macos-apple-silicon
cp env.example .env
chmod 0600 .env
```

需要 Apple Silicon Mac、Docker Desktop Linux container engine 和 Compose
v2。建议使用 Apple Virtualization framework 并启用 Rosetta。该发行包通过
Docker Desktop 仿真 Linux/amd64 镜像，不是原生 arm64 OpenD。

编辑 `.env` 后，在私有终端首次登录并启动：

```bash
./futu-opend init
```

登录成功后，当前前台 OpenD 已经提供 API 服务。该会话结束或主机重启后，
使用 remembered 状态后台启动：

```bash
./futu-opend start
```

## Linux/amd64

Linux 用户下载同一 Release 中的：

- `futu-opend-10.10.7008-r2-linux-amd64.tar.gz`
- `futu-opend-10.10.7008-r2-linux-amd64.tar.gz.sha256`

校验方式为：

```bash
sha256sum -c futu-opend-10.10.7008-r2-linux-amd64.tar.gz.sha256
```

其余配置和管理命令与 macOS 包一致。

## 本次变更

- tag 发布工作流同时生成 Linux/amd64 与 macOS Apple Silicon 宿主包。
- macOS 启动器在运行 Docker 前验证 `Darwin/arm64`、Compose v2、Docker
  engine 可访问性及 Linux container 模式。
- 兼容 macOS 自带 LibreSSL：不支持 `-traditional` 时使用其默认 PKCS#1
  输出，并继续验证密钥必须是未加密 PKCS#1 格式和宿主机模式 `0600`。
- 错误平台会在接触 Docker 和状态卷前失败。
- 两个包保持 digest 固定、无源码、非 root OpenD、loopback API、默认关闭
  Telnet/WebSocket 和保留登录状态卷的原有安全边界。

## 已知限制

- macOS 支持属于 Apple Silicon 宿主兼容层，不是 Linux/arm64 或 macOS 原生
  OpenD 构建；性能和稳定性取决于 Docker Desktop 的 amd64 仿真。
- 首次登录或重新认证必须由用户在私有终端完成，可能需要手机或图形验证码。
- 容器健康检查不代表登录成功或 API 业务就绪；真实只读 SDK 验收仍由用户
  单独执行。
- OpenD 归档摘要是经过审查的 TOFU 一致性锁，不是富途发布的签名。
- 本项目与富途证券没有隶属关系，不解锁交易、不下单，也不授予行情权限。
